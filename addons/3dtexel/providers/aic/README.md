# Art Institute of Chicago Provider Adapter

Integrates the Art Institute of Chicago Open Access collection (over 50,000 public domain / CC0 masterworks, including Impressionist, American, and Asian art) into the 3dtexel asset library.

## Capabilities
- Search Chicago Institute artworks with IIIF image endpoints
- Multi-tier downloads (`orig`, `2048`, `843`)
- Creative Commons CC0 1.0 Universal attribution and provenance
- 100% offline testing with synthetic fixtures
