# Kenney Provider Adapter

Independent Godot 4.4+ editor adapter for [Kenney](https://kenney.nl/assets) implementing Provider Contract v1.

## Supported Features & Capabilities
- **Asset Types**: 3D Models, 2D Sprites/Images, Audio/SFX, Prototyping Textures.
- **Authentication**: Zero API keys or credentials required (`key_env: []`).
- **Packs & Formats**: Direct ZIP bundles containing game-ready glTF, FBX, OBJ, WAV, OGG, and PNG resources.
- **Licensing**: CC0 1.0 Universal (Public Domain).
- **Attribution**: Preserves creator credit to Kenney (https://kenney.nl).
- **Pacing & Cache**: 500ms request pacing, disk cache in `user://kenney_cache`.
