# NIAID BioArt Provider for 3DTexel

Integrates the National Institute of Allergy and Infectious Diseases (NIAID) BioArt Source library into the Godot 4.4+ Asset Library.

## Features
- **High-Resolution Biological Graphics**: Cellular structures, immunology diagrams, viruses, bacteria, laboratory instruments, and medical icons.
- **License**: Public Domain (United States Government work).
- **Offline / Mock Testing**: Fully testable offline with synthetic JSON fixtures.
- **Pacing & Cache**: 500ms pacing and disk cache.
