# Prelinger Archives Provider for 3DTexel

Integrates the historic Prelinger Archives (60,000+ ephemeral, educational, and industrial films and audio) into the Godot 4.4+ Asset Library.

## Features
- **Historical Audio & Video**: Educational films, vintage newsreels, advertisements, and sound design materials.
- **License**: Public Domain Mark 1.0 (free for commercial and personal game development).
- **Offline / Mock Testing**: Fully testable offline with synthetic JSON fixtures.
- **Pacing & Cache**: 500ms pacing and disk cache.
