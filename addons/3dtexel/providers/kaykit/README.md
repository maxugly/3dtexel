# KayKit Provider for 3DTexel

Integrates Kay Lousberg's (KayKit) modular low-poly 3D game asset kits into the Godot 4.4+ Asset Library.

## Features
- **Modular Game Kits**: Dungeons, medieval towns, space stations, characters, and props.
- **Godot Optimized**: Clean glTF / GLB meshes utilizing shared single texture atlases for low draw calls.
- **License**: Creative Commons CC0 1.0 Universal (Public Domain).
- **Offline / Mock Testing**: 100% testable offline with synthetic JSON fixtures.
- **Pacing & Cache**: 500ms pacing between network requests, disk cache for catalogs and thumbnails.
