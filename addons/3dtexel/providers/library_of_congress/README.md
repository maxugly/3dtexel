# Library of Congress Provider Adapter

Integrates the Library of Congress Prints & Photographs and Maps collections (over 1 million public domain historical images, architectural drawings, Civil War photography, and vintage maps) into the 3dtexel asset library.

## Capabilities
- Search prints, photographs, and historical maps
- Multi-tier downloads (`orig`, `2048`, `1024`)
- Public Domain license compliance and archival provenance
- 100% offline testing with synthetic fixtures
