# Nationalmuseum Sweden Provider Adapter

Integrates Sweden's Nationalmuseum Open Access collection (over 40,000 public domain / CC0 masterworks, Scandinavian art, and sculptures) into the 3dtexel asset library.

## Capabilities
- Search artworks by query and category
- Download multi-tier high-resolution images (`orig`, `2048`, `1024`)
- Full CC0 license preservation with complete artist provenance
- 100% offline testing with synthetic fixtures
