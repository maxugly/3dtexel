# Biodiversity Heritage Library (BHL) Provider Adapter

Integrates the Biodiversity Heritage Library collection (over 150,000 public domain botanical plates, Audubon bird folios, insect taxonomic drawings, and natural history engravings ideal for game textures and illustrations) into the 3dtexel asset library.

## Capabilities
- Search botanical plates and wildlife illustrations
- Multi-tier downloads (`orig`, `2048`, `1024`)
- Public Domain license compliance and BHL provenance
- 100% offline testing with synthetic fixtures
