# NYPL Digital Collections Provider for 3DTexel

Integrates the New York Public Library's 180,000+ public domain digital assets into the Godot 4.4+ Asset Library.

## Features
- **Historical Cartography & Prints**: Antique city maps, architectural blueprints, vintage botanical illustrations, illuminated manuscripts, and NYC historical photographs.
- **High-Resolution Direct Image Downloads**: Uncompressed scans from NYPL preservation repositories.
- **License**: Public Domain (No Copyright - United States).
- **Authentication**: Optional free API key via `NYPL_API_TOKEN`.
- **Offline / Mock Testing**: Fully testable offline with synthetic JSON fixtures.
- **Pacing & Cache**: 500ms pacing and disk cache.
