# USGS Multimedia & 3DEP Provider for 3DTexel

Integrates the U.S. Geological Survey (USGS) multimedia gallery and 3D Elevation Program (3DEP) datasets into the Godot 4.4+ Asset Library.

## Features
- **3D Elevation Program (3DEP)**: High-precision digital elevation models (DEMs), 3D terrain meshes (GLB), and topographic heightmaps.
- **Geological Photography**: Volcanic activity, earthquakes, satellite imagery, aerial photography, rock/mineral surface textures.
- **License**: Public Domain (United States Government work).
- **Offline / Mock Testing**: Fully testable offline with synthetic JSON fixtures.
- **Pacing & Cache**: 500ms pacing and response disk caching.
