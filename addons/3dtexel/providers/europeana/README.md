# Europeana Collections Provider Adapter

Integrates Europeana Collections (the unified digital platform for European cultural heritage from thousands of European museums, archives, and libraries) into the 3dtexel asset library.

## Capabilities
- Search open cultural heritage assets across European institutions
- Multi-tier downloads with IIIF image support (`orig`, `2048`, `1024`)
- Open rights compliance (CC0 / Public Domain / CC-BY) with institutional provenance
- 100% offline testing with synthetic fixtures
