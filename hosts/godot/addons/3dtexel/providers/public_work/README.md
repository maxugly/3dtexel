# Public Work Provider for 3DTexel

Connects 3DTexel to Public Work's curated visual search engine, unlocking high-resolution public domain paintings, architectural sketches, antique maps, botanical drawings, and vintage posters.

## Features
- **Aesthetic Visual Search**: High aesthetic curation covering world archives and museum galleries.
- **Multiple Resolutions**: High-res original art, 2048px, 1024px, and thumbnail previews.
- **In-Game Art & Material Decals**: Perfect for museum interiors, canvas decals, architectural frescoes, and environmental textures.
- **Offline Tests**: 100% offline contract and regression tests with mock client responses.
