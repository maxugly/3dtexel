# Freesound Provider for 3DTexel

Connects 3DTexel to Freesound.org's vast database of over 500,000 game sound effects, ambience loops, Foley impacts, creature vocals, and UI tones.

## Features
- **Extensive Audio Library**: Sound effects, footsteps, UI blips, ambient environments, explosions, weapons, and musical elements.
- **Audio Formats**: Direct downloads in WAV, OGG, and MP3 formats with preview waveforms.
- **Automatic License Filtering & Sidecars**: Accurately tags CC0 vs CC-BY sounds; generates proper attribution sidecars for game credits.
- **Offline Tests**: 100% offline contract and regression tests with mock client responses.
