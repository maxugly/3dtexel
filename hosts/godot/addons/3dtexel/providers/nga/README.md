# National Gallery of Art Provider for 3DTexel

Integrates the National Gallery of Art (NGA) Open Access collections into the Godot 4.4+ Asset Library.

## Features
- **50,000+ Masterworks**: World-famous paintings, oil paintings, drawings, and vintage illustrations (Monet, Vermeer, Rembrandt, Da Vinci, Van Gogh, Cassatt).
- **High Resolution**: 2K, 1K, and full-resolution image downloads.
- **License**: Creative Commons Zero (CC0 1.0 Universal / Open Access).
- **Offline / Mock Testing**: Fully testable offline with synthetic JSON fixtures.
- **Pacing & Cache**: 500ms pacing and disk cache.
