# DigitaltMuseum Provider Adapter

Integrates DigitaltMuseum's open cultural heritage repository (photographs, folk art, historical artifacts, and 3D scans from museums across Sweden and Norway) into the 3dtexel asset library.

## Capabilities
- Search museum artifacts across Nordic collections
- Filter by category (`image`, `material`, `model`, `all`)
- Download 3D models (GLB) and high-resolution images (`orig`, `1200`, `400`)
- Creative Commons CC0 and Public Domain license compliance
- 100% offline testing with synthetic fixtures
