# Finnish National Gallery (Kansallisgalleria) Provider Adapter

Integrates the Finnish National Gallery Open Access collection (over 25,000 public domain / CC0 masterworks from Ateneum, Sinebrychoff, and Kiasma) into the 3dtexel asset library.

## Capabilities
- Search Finnish and European masterworks by query and category
- Multi-tier high-resolution image downloads (`orig`, `2048`, `1024`)
- Creative Commons CC0 license attribution with full artist provenance
- 100% offline testing with synthetic fixtures
