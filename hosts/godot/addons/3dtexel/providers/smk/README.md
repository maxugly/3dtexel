# SMK Open Provider for 3DTexel

Integrates Denmark's National Gallery (Statens Museum for Kunst - SMK Open) collection of 40,000+ public domain artworks into the Godot 4.4+ Asset Library.

## Features
- **Danish & European Masterworks**: Vilhelm Hammershøi, Lucas Cranach, Christoffer Wilhelm Eckersberg, P.S. Krøyer.
- **High Resolution**: 2K, 1K, and IIIF master downloads.
- **License**: Creative Commons Zero (CC0 1.0 Universal).
- **Offline / Mock Testing**: Fully testable offline with synthetic JSON fixtures.
- **Pacing & Cache**: 500ms pacing and disk cache.
