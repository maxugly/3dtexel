# NIH 3D Provider for 3DTexel

Integrates the National Institutes of Health (NIH) 3D model repository into the Godot 4.4+ Asset Library.

## Features
- **Scientific & Medical 3D Models**: Anatomical organs (heart, brain, skeleton), viruses, molecular proteins, DNA, and laboratory equipment.
- **Direct Formats**: glTF/GLB, STL, and OBJ models ready for games and simulation.
- **License**: Public Domain (US Government work) / Creative Commons CC0.
- **Offline / Mock Testing**: Fully testable offline with synthetic JSON fixtures.
- **Pacing & Cache**: 500ms pacing and response disk caching.
