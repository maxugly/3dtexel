# David Rumsey Map Collection Provider for 3DTexel

Connects 3DTexel to the David Rumsey Historical Map Collection of 150,000+ antique maps, atlases, globes, charts, and maritime cartography.

## Features
- **Historical Cartography**: Detailed parchment maps, antique star charts, and geographical surveys from 1500 to the 20th century.
- **Parchment & Paper Textures**: High-resolution scanned fibers, antique ink, and cartographic illustrations.
- **IIIF Integration**: Dynamic tile and resolution delivery via Luna IIIF endpoints (max, 2048px, 1024px, 512px).
- **Offline Tests**: 100% offline contract and unit tests with mock responses.
