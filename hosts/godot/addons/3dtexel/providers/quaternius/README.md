# Quaternius Provider for 3DTexel

Integrates Quaternius's game-ready 3D model packs into the Godot 4.4+ Asset Library.

## Features
- **3D Model Packs**: Characters, modular environments, mechs, props, and nature assets.
- **Game Engine Ready**: Rigged, animated, modular assets available in glTF / GLB, FBX, and OBJ formats.
- **License**: Creative Commons CC0 1.0 Universal (Public Domain).
- **Offline / Mock Testing**: Fully testable offline with synthetic JSON fixtures.
- **Pacing & Cache**: 500ms pacing between network requests, disk cache for catalogs and thumbnails.
