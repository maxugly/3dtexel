# INAH Mediateca México Provider Adapter

Integrates the Instituto Nacional de Antropología e Historia (INAH) Mediateca repository (pre-Columbian codices, Maya/Aztec archaeological artifacts, stone stelae, and historical photography of Mexico) into the 3dtexel asset library.

## Capabilities
- Search Mesoamerican codices, glyphs, and archaeological treasures
- Multi-tier downloads (`orig`, `2048`, `1024`)
- Public Domain license compliance and INAH archival provenance
- 100% offline testing with synthetic fixtures
