# BnF Gallica Provider Adapter

Integrates the Bibliothèque nationale de France Gallica digital library (over 6 million public domain works, historical prints, vintage maps, illuminated manuscripts, and posters) into the 3dtexel asset library.

## Capabilities
- Search Gallica prints and maps via SRU/REST query
- IIIF image endpoints with multi-tier download support (`orig`, `2048`, `512`)
- Public Domain license compliance and archival provenance
- 100% offline testing with synthetic fixtures
