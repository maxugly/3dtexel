# Old Book Illustrations Provider for 3DTexel

Connects 3DTexel to Old Book Illustrations, providing 18th-20th century Victorian engravings, woodcuts, decorative borders, and character sketches.

## Features
- **Public Domain Book Art**: High-resolution scanned book plates from works by Gustave Doré, Arthur Rackham, John Tenniel, Grandville, and Victorian masters.
- **Multiple Resolutions**: High-res original scans, 2048px, 1024px, and thumbnail previews.
- **Engraving & Line Art Textures**: Ideal for stylized game art, inked decals, parchment overlays, and vintage UI.
- **Offline Tests**: 100% offline contract and regression tests with mock client responses.
