# Wikimedia Commons Provider Adapter

Integrates Wikimedia Commons' vast repository of millions of public domain artworks (Category:PD-Art), historical photography, and CC0 cultural media into the 3dtexel asset library.

## Capabilities
- Search media across Wikimedia Commons with MediaWiki API
- Multi-tier downloads from Wikimedia CDN (`orig`, `2048`, `1024`)
- Public Domain and CC0 compliance with artist provenance
- 100% offline testing with synthetic fixtures
