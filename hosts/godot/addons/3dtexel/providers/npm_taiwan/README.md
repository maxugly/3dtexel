# National Palace Museum Taiwan Provider Adapter

Integrates the National Palace Museum Open Data repository (Chinese imperial antiquities, jade artifacts, Song/Ming porcelain, calligraphy, and classical landscape paintings) into the 3dtexel asset library.

## Capabilities
- Search ancient Chinese imperial artifacts and paintings
- Multi-tier high-resolution image downloads (`orig`, `2048`, `1024`)
- Open Data / Creative Commons CC0 license attribution and provenance
- 100% offline testing with synthetic fixtures
