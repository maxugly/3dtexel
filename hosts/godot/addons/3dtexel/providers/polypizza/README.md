# Poly Pizza Provider for 3DTexel

Integrates Poly Pizza's 10,000+ low-poly 3D models into the Godot 4.4+ Asset Library.

## Features
- **10k+ Low-Poly 3D Props**: Free low-poly models created for games and VR.
- **Direct GLB**: Native glTF/GLB download for instant use in Godot scenes.
- **Licensing**: Filterable CC0 (Public Domain) and CC-BY (Attribution) assets.
- **API Authentication**: Free API key via `POLYPIZZA_API_KEY` environment variable or session token (`x-auth-token`).
- **Offline / Mock Testing**: Fully testable offline with synthetic JSON fixtures.
- **Pacing & Cache**: 500ms request pacing and disk caching for catalog responses and thumbnails.
