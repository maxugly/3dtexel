# Rijksmuseum Provider for 3DTexel

Integrates the Rijksmuseum's Rijksstudio collection of 700,000+ open-access artworks into the Godot 4.4+ Asset Library.

## Features
- **Dutch Masterworks**: Rembrandt van Rijn, Johannes Vermeer, Frans Hals, Jan Steen, and historical prints and textures.
- **Ultra High-Resolution**: Full multi-megapixel images and web previews.
- **License**: Creative Commons Zero (CC0 1.0 Universal).
- **Authentication**: Optional personal API key via `RIJKSMUSEUM_API_KEY` (public demo key included by default).
- **Offline / Mock Testing**: Fully testable offline with synthetic JSON fixtures.
- **Pacing & Cache**: 500ms pacing and response disk caching.
