# Nasjonalmuseet Norway Provider Adapter

Integrates Norway's National Museum collection (over 40,000 public domain / CC0 artworks, Edvard Munch masterworks, Scandinavian landscapes, and tapestries) into the 3dtexel asset library.

## Capabilities
- Search Norwegian masterworks by title, artist, or query
- Multi-tier high-resolution image downloads (`orig`, `2048`, `1024`)
- Creative Commons CC0 license attribution and complete provenance
- 100% offline testing with synthetic fixtures
