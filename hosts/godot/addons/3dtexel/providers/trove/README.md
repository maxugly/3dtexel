# Trove Australia Provider Adapter

Integrates the National Library of Australia's Trove visual media repository (historical photographs, maps, illustrations, landscape art, and Australian cultural memory) into the 3dtexel asset library.

## Capabilities
- Search historical images and maps across Australian institutional archives
- Multi-tier image downloads (`orig`, `1600`, `800`)
- Public Domain and CC license preservation with source provenance
- 100% offline testing with synthetic fixtures
