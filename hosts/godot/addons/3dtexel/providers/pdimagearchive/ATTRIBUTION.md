# Public Domain Image Archive Attribution & Terms of Use

The Public Domain Image Archive (PDIA) is a hand-curated repository indexing over 100,000 public domain artworks, vintage engravings, rare book illustrations, and historical photographs across 192 world cultural institutions.

- **Institution / Community**: Public Domain Image Archive (PDIA / Public Domain Review)
- **Portal**: https://pdimagearchive.org/
- **License**: Public Domain Mark 1.0 (Public Domain / CC0)
- **License URI**: https://creativecommons.org/publicdomain/mark/1.0/
- **Attribution Policy**: All indexed media is in the public domain. Citing the original artist and source repository is recommended.
- **Commercial Use**: Permitted without restriction for commercial and personal game development, materials, canvas textures, level props, and environmental decals.
