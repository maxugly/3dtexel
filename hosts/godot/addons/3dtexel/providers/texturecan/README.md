# TextureCan Provider for 3DTexel

Integrates TextureCan's library of CC0 PBR textures into the Godot 4.4+ Asset Library.

## Features
- **PBR Textures**: Full PBR map sets (Color/Albedo, Normal OpenGL, Roughness, Height/Displacement, Ambient Occlusion).
- **Multiple Resolutions**: 1K, 2K resolution variants.
- **License**: Creative Commons CC0 1.0 Universal (Public Domain).
- **Offline / Mock Testing**: Fully tested using synthetic JSON fixtures.
- **Pacing & Cache**: 500ms pacing between network calls, ETag / 304 caching.
