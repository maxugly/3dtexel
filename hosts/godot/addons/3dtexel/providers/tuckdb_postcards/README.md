# TuckDB Postcards Provider for 3DTexel

Connects 3DTexel to the TuckDB Postcards collection of 150,000+ antique postcards, vintage lithographs, and ephemera.

## Features
- **Historical Ephemera Textures**: Scans of front and back postcard art, postmarks, and vintage print textures.
- **Multiple Resolutions**: High-res original scans, 2048px, 1024px, and thumbnail previews.
- **Game Props & Decals**: Excellent for in-game collectible items, lore letters, bulletin boards, and period set dressing.
- **Offline Tests**: 100% offline contract and regression tests with mock client responses.
