# Paris Musées Provider for 3DTexel

Integrates the City of Paris public museums open access collections (Paris Musées) into the Godot 4.4+ Asset Library.

## Features
- **14 City of Paris Museums**: Musée Carnavalet, Petit Palais, Maison de Victor Hugo, Musée d'Art Moderne, Musée de la Vie Romantique, Palais Galliera.
- **Masterworks & Historic Art**: Paintings, drawings, prints, sculptures, and architectural photographs.
- **License**: Creative Commons Zero (CC0 1.0 Universal / Open Access).
- **Authentication**: Optional personal API key via `PARIS_MUSEES_API_KEY`.
- **Offline / Mock Testing**: Fully testable offline with synthetic JSON fixtures.
- **Pacing & Cache**: 500ms pacing and disk caching.
