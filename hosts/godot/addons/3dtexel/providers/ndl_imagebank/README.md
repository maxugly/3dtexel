# NDL Image Bank Japan Provider Adapter

Integrates the National Diet Library Image Bank (vintage Japanese visual art, Ukiyo-e woodblock prints by Hokusai and Hiroshige, Edo natural history illustrations, and classic patterns) into the 3dtexel asset library.

## Capabilities
- Search Japanese woodblock prints and vintage artworks
- Multi-tier high-resolution image downloads (`orig`, `2048`, `1024`)
- Public Domain license compliance and artist provenance
- 100% offline testing with synthetic fixtures
